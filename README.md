# Reactive Kanban Board (Drag & Drop Interface)

A high-performance, interactive Kanban board built to simulate premium project management tools like Trello. This project demonstrates advanced frontend reactivity, state management, and smooth user interactions.

## Features
* **Advanced Drag & Drop:** Seamless card movement across columns powered by modern DnD libraries.
* **Full CRUD Capabilities:** Create, read, update, and delete tasks on the fly.
* **State Synchronization:** Real-time state updates ensuring no data lag during interaction.
* **Smart Filtering:** Quickly filter tasks by tags and priority levels.
* **Data Persistence:** Built-in `localStorage` integration to save your workflow automatically.
